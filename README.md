# 📅 План на неделю

Уютный планировщик задач на неделю в тёплой землистой палитре (Stone Beige, Smoky Taupe, Muted Olive, Espresso Depth, Soft Bronze). Задачи по дням, трекер привычек, приоритеты, график прогресса и итоги недели. Весь список сохраняется прямо в браузере — без регистрации, серверов и установки.

![Скриншот приложения](assets/screenshot.png)

## ✨ Возможности

- **Недели вперёд и назад** — стрелки `‹ ›` листают недели, кнопка «Текущая неделя» возвращает к сегодняшнему дню. Задачи можно планировать на любые даты, в том числе на будущие недели.
- **7 дней недели** — каждый день с цветной шапкой в своём оттенке и реальной датой; сегодняшний день подсвечивается.
- **Добавление задач** — через общую форму сверху или кликом прямо по свободному месту в карточке дня. Можно указать время: `11 00 Написать письмо` превратится в задачу на 11:00.
- **Отметка выполнения** — клик по задаче зачёркивает её и подсвечивает.
- **Редактирование** — кнопка-карандаш ✎ на задаче открывает поле правки текста и времени.
- **Перетаскивание** — задачи и приоритеты переносятся между днями перетаскиванием (мышью и пальцем на сенсорных экранах). Перенесённые задачи выделяются рамкой и встают в начало списка.
- **Перенос невыполненного** — стрелка `→` в шапке дня переносит незавершённые задачи на завтра (с воскресенья — на понедельник следующей недели). При многократном переносе появляется мягкое напоминание об актуальности задачи.
- **Фокус дня** — кнопка открывает окно с задачами выбранного дня для спокойной работы над ними.
- **Топ-3 приоритета** — до трёх главных дел на день в виде чипов; выбираются из задач дня или вводятся вручную, переносятся между днями перетаскиванием.
- **Еженедельный прогресс** — столбики по дням (запланировано/выполнено) и кольцо с процентом; всегда считается по текущей неделе.
- **Трекер привычек** — свой список привычек, отметки по дням открытой недели и полоска прогресса для каждой.
- **Итоги недели** — карточки «Что было успешно», «Что можно улучшить» и «За что я благодарен» для каждой недели свои.
- **Очистка** — «Очистить выполненные» и «Очистить неделю» действуют на открытую неделю (список привычек при этом сохраняется).
- **Тёмная тема** — переключатель с сохранением выбора; тёмная тема выдержана в кофейных тонах палитры.
- **Автосохранение** — задачи, привычки, приоритеты и заметки хранятся в `localStorage`; данные из старых версий переносятся автоматически.
- **Адаптивная вёрстка** — корректно отображается на десктопе, планшете и телефоне.
- **Мобильная версия** — нижняя панель с вкладками «Обзор», «Неделя», «Фокус» и «Треккер», чтобы не листать всё подряд. Добавление задач и привычек — через плавающую кнопку «+»; тема переключается иконкой в углу.

## 🚀 Как запустить

Приложение — это один HTML-файл без зависимостей и сборки.

1. Скачай или клонируй репозиторий:
   ```bash
   git clone https://github.com/mailolgaku-debug/week-planner.git
   ```
2. Открой файл `index.html` в любом современном браузере (двойной клик по файлу).

Готово — можно пользоваться офлайн.

## 🛠 Технологии

- HTML
- CSS (container queries, grid, `color-mix`, тёмная тема через `data-theme`)
- Чистый JavaScript (без фреймворков), хранение в `localStorage`

## 💾 Где хранятся данные

Все задачи сохраняются локально в твоём браузере (`localStorage`), на текущем устройстве. Задачи привязаны к конкретным датам (ключи `soft-week-*-v2`); при первом запуске новая версия автоматически переносит данные старого формата. Данные не отправляются никуда и не синхронизируются между устройствами.
